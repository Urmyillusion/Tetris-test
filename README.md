# 俄罗斯方块 (Tetris)

单文件、零依赖的网页版俄罗斯方块游戏，使用 HTML + Canvas + 原生 JavaScript 实现。

## 运行方式

无需安装任何环境或第三方库，直接用浏览器打开 `tetris.html` 即可：

- 双击 `tetris.html` 文件，或
- 拖拽到 Chrome / Edge / Firefox 等浏览器窗口中打开

## 功能特性

- 标准 **10 × 20** 游戏区域
- **七种方块**（I / O / T / S / Z / J / L），采用 7-bag 洗牌随机生成，分布均匀
- 支持左右移动、旋转（含踢墙修正）、软降、硬降
- 完整的边界与堆叠碰撞检测
- 满行消除、计分与等级递增，等级越高下落速度越快
- 右侧面板实时显示**下一个方块预览、当前分数、等级与消行数**
- 支持**暂停、重新开始、游戏结束判定**（出生点被占或锁定时溢出顶部）

## 键位说明

| 按键 | 功能 |
| --- | --- |
| ← / → | 左右移动 |
| ↑ | 旋转 |
| ↓ | 软降（加速下落，每格 +1 分） |
| 空格 | 硬降（直接落底，每格 +2 分） |
| P | 暂停 / 继续 |
| R | 重新开始 |

界面右侧同时提供键位表与「重新开始」按钮；游戏结束后按 R 或空格即可重新开始。

## 计分与等级规则

- 消行得分 = 基础分 × 当前等级，基础分：1 行 100 / 2 行 300 / 3 行 500 / 4 行 800
- 软降每格 +1 分，硬降每格 +2 分
- 每累计消除 10 行升 1 级
- 重力下落间隔 = `800 × 0.85^(等级-1)` 毫秒，下限 80 毫秒，等级越高速度越快
